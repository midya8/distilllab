KL = binary target/rest KL + teacher rest mass × conditional non-target KL. The student gradient also splits. The original soft cross-entropy differs from KL by a teacher-only entropy offset. This offset does not affect the student update, but it does affect the printed loss. T² scaling does not make the exact gradient temperature-invariant.

Each branch recomputes actual tanh-MLP gradients using an independent scalar reverse-mode engine in this page. Native Python uses analytic backprop. First-order descent is local: a finite step can raise loss. Different teacher tails also change the objective, so both own-teacher and original-teacher KL changes remain visible.

The boundary of the claim

The 21 original controls are three training rows from each of seven archived student states (six trained arms and the initialization). Seven extra controls are explicitly synthetic. They are not new held-out evidence. A teacher-tail permutation need not preserve class meaning. No selected tail, step or row establishes a causal account of the original distillation gain or a generalization benefit.

True excluded-class logsumexp is used, not a finite subtract-1000 mask or 1 minus a rounded target probability. Extreme floating-point masses can underflow to zero; the conditional distribution is still evaluated from its own logits. Raw roundoff residuals are exposed, not clamped into a proof.
